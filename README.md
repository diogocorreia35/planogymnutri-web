# planogymnutri-web
# O projeto consiste num site de planos de ginásio e nutrição personalizados, desenvolvido de acordo com o objetivo físico de cada pessoa. O utilizador pode indicar o seu objetivo físico e receber um plano de treino e alimentação adaptado às suas necessidades.
